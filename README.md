# AuraLab

Welcome to **AuraLab** (also known as *The Incubator*), a central dashboard and hub designed to host specialized tools and micro-apps built for growth, health, and academic precision. 

The project features a modern, responsive user interface utilizing a sleek glassmorphism design language with interactive elements like fluid background animations and full light/dark theme switching.

---

## 🚀 What the Project Does

AuraLab serves as a single launchpad for various standalone web applications. Instead of managing multiple separate bookmarks or domains, everything is unified under a beautiful, responsive grid interface. 

### Current Micro-Apps Included:
* **Iron Habit (Fitness):** A dedicated gym habit-tracking application meant to log consistency, track workout volume, and maintain workout streaks.
* **AuraPlotter (Education):** A clean, student-focused graph plotter designed to visualize mathematical functions and data sets with zero friction.
* **AuraGroq (Artificial Intelligence):** A custom high-speed graphical user interface (GUI) for Groq Cloud, allowing users to bring their own API key for lightning-fast inference and full control over system prompts.
* **Terminal One (Finance & Markets):** A focused workspace for monitoring market liquidity and price action featuring a multi-chart TradingView integration with real-time news provided via Finnhub.

---

## 🔮 Future Roadmap

AuraLab is built to be an evolving ecosystem. **In the future, many random apps, specialized utilities, and experimental micro-tools will be continuously added to this hub.** Whether it's a new utility for daily organization, a niche calculator, or an advanced AI integration, the platform is structured to expand seamlessly as new ideas incubate.

---

## 🎨 Design & UI Features

* **Glassmorphic Elements:** Modern UI components with semi-transparent backgrounds, subtle borders, and deep backdrop blurs.
* **Universal Light/Dark Mode:** A quick theme toggle built into the navigation bar for high contrast day or night usage.
* **Responsive Framework:** Tailored layouts spanning from large desktop monitors down to ultra-compact screens like mobile foldables.
